# GreenAura Showcase

Create a premium, modern, and visually stunning plant shop landing page called “GreenAura” as a complete React Vite project with a professional folder structure and reusable components. The design should deliver an Apple-level premium experience with ultra-smooth animations, elegant transitions, and high-end minimal aesthetic inspired by top Framer Motion websites. Use React with Tailwind CSS for styling and implement advanced animations using Framer Motion (including parallax scrolling effects, fade-ins, staggered reveals, smooth hover lifts, and subtle micro-interactions). Build it with a fully responsive, mobile-first layout that looks perfect on mobile, tablet, laptop, and desktop. Include a sticky navbar with logo, navigation links (Home, Shop, Story, Contact) that enable smooth scrolling to sections, and a prominent "Shop Now" button. Use a luxurious color palette of deep green (#0F3D2F), sage (#A8B5A2), cream (#F5F0E8), and olive, paired with Playfair Display for elegant headings and Inter for clean body text. Feature high-quality plant photography throughout. The page must include the following sections: a full-screen immersive hero with bold headline, tagline, and dual CTAs; a featured products grid with hover animations and clickable cards showing plant name, price, and image; a brand story section with image and narrative; a "Why Choose Us" section with four icon-based benefits; an auto-playing testimonials slider; a strong final call-to-action section; and a clean footer with social links. Add production-ready features like lazy loading for images, smooth scrolling, animated buttons, and interactive elements. Ensure the final output is clean, well-structured, component-based code that delivers an impressive, premium user experience like a real high-end startup website.
